# ErrdayCode

A central place for my course notes, daily coding exercises, and small programming practice scripts. 

## Purpose

This repo is meant to track my technical learning and build a steady habit of daily coding. It serves as a personal knowledge base for:
- **Daily practice:** Small programs and problem-solving exercises.
- **Course notes:** Key concepts and references from courses I'm taking.
- **Language exploration:** Re-implementing solutions across different languages (e.g., Python, Java) to sharpen fundamentals across different stacks.
